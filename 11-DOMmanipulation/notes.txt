To change any element or do anything with the element we need to first grab the element.
Now there are several ways for grabbing an element:
document.querySelector(id-> like #id or class-> like .class)
document.querySelectorAll(id or class or name-> like button)
docunemt.get -> this will give many options like getElementByClassName or getElementByName or getElementByTagName or getElementById

Now once we have grabbed the element we need to choose the event which will trigger the change and for which we use addEventListener(params).
here inside the paranthesis there are 2 parameters the first one is the event and the second parameter is the block of code or the function that should be performed.
